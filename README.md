# Colorwork Studio

뜨개 차트 이미지를 셀 단위로 재구성하고 색상과 기호를 편집하는 로컬 웹 앱의 첫 버전입니다.

## 실행

```powershell
npm.cmd install
npm.cmd run dev
```

Chrome에서 `http://127.0.0.1:5173/`을 엽니다. 배포용 파일은 `npm.cmd run build`로 생성합니다.

## 기본 작업 순서

1. **Upload image**에서 PNG, JPEG, WebP 이미지를 고릅니다.
2. 이미지에서 차트 격자 하나만 드래그해 파란 선택 상자를 만듭니다. 행·열 수만 입력해서는 **Reconstruct chart** 버튼이 활성화되지 않습니다. 추정된 행·열 수가 원본과 다르면 수정합니다.
3. 필요한 경우 범례 영역을 별도로 드래그하고 **Read legend names**를 누릅니다. 감지된 이름을 확인합니다.
4. **Reconstruct chart**를 눌러 셀을 가져옵니다. 원본과 재구성 화면을 번갈아 확인할 수 있습니다.
5. 오른쪽 패널에서 프로젝트에 속한 차트를 전환하고 색을 바꿉니다. **Add color group**으로 D와 같은 새 그룹을 만든 뒤 **Paint**를 선택하고 원하는 셀을 드래그해 그룹을 지정합니다. 한 프로젝트의 차트는 팔레트를 공유합니다.
6. 셀을 선택하면 색상 그룹, `No stitch`, `M1L`, `M1R`, `M1`, `YO`, `SSK`, `K2tog` 기호를 보정할 수 있습니다. 원본의 기호가 보이는 셀을 표본으로 지정해 같은 모양을 찾을 수도 있습니다.
7. 작업은 브라우저에 자동 저장됩니다. 오른쪽의 **Automatic JSON backup → Choose backup folder**에서 폴더를 한 번 선택하면 프로젝트별 JSON 파일도 자동 갱신됩니다. **Download JSON**은 수동 백업이며, **Projects → Open backup file**로 복원할 수 있습니다.
8. **Save as PDF**는 각 차트를 별도 페이지에 출력합니다.

## 인식 범위

- 색상 그룹, 빨간 반복 테두리, 일부 `No stitch` 영역을 이미지에서 추정합니다.
- 범례의 문자 이름을 OCR로 읽고, 확인된 이름과 원본 기호 모양을 연결합니다. 디자이너마다 기호 그림이 다를 수 있어 자동 매칭 결과는 셀을 보면서 검토해야 합니다.
- 격자가 희미하거나 사진이 기울어져 있으면 행·열 수와 셀 인식에 오류가 생길 수 있습니다. 가져오기 화면의 격자 선과 편집 도구로 수정할 수 있습니다.
- 첫 버전은 이미지 파일을 입력으로 사용합니다. PDF 페이지를 직접 가져오지는 않습니다.

프로젝트와 이미지는 서버로 전송하지 않고 현재 브라우저의 IndexedDB에 보관합니다. OCR 실행 파일과 영어 학습 데이터는 빌드 시 `public/ocr/`로 복사되어 로컬에서 사용됩니다.

## 자동 JSON 백업

- 폴더를 연결한 뒤 차트를 가져오거나 프로젝트를 편집하면 마지막 변경으로부터 약 1.5초 후 파일을 갱신합니다. 셀을 드래그하는 매 순간 파일을 쓰지 않습니다.
- 각 프로젝트는 `colorwork-<프로젝트 ID>.colorwork.json` 파일을 사용합니다. 프로젝트 이름을 바꿔도 같은 파일을 갱신합니다.
- 그날 처음 기존 파일을 덮어쓸 때 날짜가 들어간 이전 버전 파일을 한 번 보존합니다.
- 폴더 파일이 앱 밖에서 바뀌어 브라우저 데이터와 다르면 자동 덮어쓰기를 멈춥니다. 오른쪽 패널에서 어느 버전을 사용할지 선택하면 다른 쪽의 복구본을 저장합니다.
- 브라우저가 폴더 쓰기를 지원하지 않거나 접근 권한이 끊기면 브라우저 내부 저장은 계속됩니다. 이때 **Download JSON**으로 수동 백업할 수 있습니다. 실제 폴더 접근 권한은 브라우저에서 허용해야 합니다.
