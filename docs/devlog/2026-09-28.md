# 2026-09-28 Colorwork Studio Development Log

## Work Summary

뜨개 차트 이미지의 색을 바꾸고 일부 셀을 직접 수정하고 싶다는 요구를 바탕으로 첫 로컬 웹 앱을 구현했다. 기존 차트의 기호 그림은 디자이너마다 다를 수 있으므로 범례의 표준 기호 이름을 인식의 출발점으로 삼았다.

## Work Completed

- React·TypeScript·Vite 앱을 만들고 차트 화면과 색상 편집 패널을 구성했다.
- 이미지에서 격자를 선택하고 행·열 수와 인쇄 번호를 보정해 셀을 재구성하는 가져오기 화면을 만들었다.
- 색상 그룹, 반복 테두리, 일부 `No stitch` 영역을 추정하고 불확실한 셀을 표시한다.
- 범례 OCR과 원본 기호 모양 매칭을 추가했다. `M1L`, `M1R`, `M1`, `YO`, `SSK`, `K2tog`를 편집·표시할 수 있다.
- 새 색상 그룹을 추가해 일부 셀에 칠하고, 그룹 병합·색 조합 저장·실행 취소·차트 추가를 지원한다.
- 프로젝트의 브라우저 저장, JSON 백업·복원, PDF 출력과 사용 방법 문서를 추가했다.
- 첨부된 회색 차트로 21×24 격자와 반복 구간, 새 그룹 칠하기, 백업·복원, PDF를 확인했다. 다른 첨부 예시로 40×16, 9×20 등 격자와 불규칙한 `No stitch` 형태를 점검했다. 범례 예시에서 여섯 기호 이름을 OCR로 읽었다.
- Chrome 2048px, 1280px, 900px 너비에서 주요 동작과 가로 넘침을 확인했다. `npm run build`를 실행해 배포용 빌드를 확인했다.

## Decisions

- 기호 이름은 표준 용어로 저장하고, 각 이미지의 기호 그림은 범례나 표본 셀을 통해 연결하도록 했다. 기호 그림만으로 기법을 단정하면 디자이너별 표기 차이를 처리하기 어렵기 때문이다.
- 새 D 그룹은 기존 A/B/C 색을 분리하는 셀 수준 편집으로 구현했다. 색상값만 바꾸는 작업과 영역 자체를 다시 분류하는 작업을 분리하기 위해서다.
- 가져오기 단계의 자동 격자 수는 추정치로 표시하고 사용자가 수정하도록 했다. 실제 예시 일부에서 자동 행 수가 1~2개 어긋났다.
- OCR 작업 파일을 앱에 포함해 인터넷 연결 없이 범례 인식을 실행하도록 했다. PDF 라이브러리는 보안 수정 버전으로 올렸다.

## Current Status

로컬 앱으로 기능을 사용할 수 있으며, 첨부 이미지 기반의 주요 흐름과 PDF 렌더링을 확인했다. 원본 기호와 셀의 자동 매칭은 이미지에 따라 누락될 수 있어 수동 확인과 보정이 필요하다. 실제 모니터에서의 읽기 편안함은 J님의 확인이 남아 있다.

- 필요하면 PDF 페이지 직접 가져오기와 더 정교한 원본 기호 매칭을 다음 버전에 추가한다.

## Work Completed - 차트 공간과 자동 JSON 백업

- 프로젝트 이름, 실행 취소, 원본·재구성 전환, 차트 목록과 추가 버튼, 차트 요약·확대를 오른쪽 사이드바로 이동했다.
- 왼쪽 차트 영역의 고정 최대 높이를 제거해 헤더 아래부터 화면 하단까지 표시하고, 세로 차트는 영역 내부에서 스크롤하도록 했다.
- 폴더 선택·권한 재연결·프로젝트별 JSON 자동 저장과 백업 상태를 사이드바에 추가했다. 폴더 파일이 달라지면 자동 덮어쓰기를 중단하고 버전을 선택하도록 했다.
- 기존 파일은 하루 첫 덮어쓰기 전에 복구본을 만들고, 버전 충돌 해결 시 선택하지 않은 쪽을 별도 파일로 보존한다.
- 2048×1000, 1280×900 화면에서 가로 넘침 없이 차트 공간이 확보되는 것을 확인했다. 16열×57단 차트의 내부 스크롤도 확인했다. 가상 폴더로 JSON 자동 갱신, 외부 변경 충돌, 양쪽 복구 흐름을 확인했고 빌드가 통과했다.

## Decisions - 차트 공간과 자동 JSON 백업

- 여러 차트는 같은 프로젝트의 팔레트를 공유하되 화면에서는 하나씩 전환한다. 차트들을 이어 붙이는 기능으로 오해하지 않도록 사이드바에 `Charts in this project`라고 표시했다.
- 원본 이미지가 JSON에 포함돼 파일이 커질 수 있으므로 마지막 편집 후 잠시 기다렸다가 기록한다. 프로젝트 이름 대신 변경되지 않는 ID를 파일명에 사용해 이름 변경 시에도 같은 파일을 갱신한다.
- 폴더 파일의 내용이 예상과 다르면 조용히 덮어쓰지 않는다. 파일 또는 브라우저 버전을 명시적으로 선택하고 복구본을 남긴다.
